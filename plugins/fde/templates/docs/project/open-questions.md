# Open questions

Purpose: what we do not know and who can answer it. The client should
never ask a question this file saw coming.
Done when: never. Empty is the goal, not the start.

Aggregated from the wiki where questions are raised at the point of use;
questions with no wiki home are authored here directly.

Every row needs an owner in "Who can answer". The record lint fails a row
without one, because a question nobody owns never gets asked.

| ID | Question | Raised | Blocks | Who can answer | Status |
|---|---|---|---|---|---|
| | | | | | |

Statuses: open, answered, overtaken.

A question raised inside a wiki node is aggregated here rather than
retyped. Where a row comes from a node, name the node beside it, so the
answer can be written back to the place that raised it.
