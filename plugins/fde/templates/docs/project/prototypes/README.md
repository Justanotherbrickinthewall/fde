# Prototypes

Purpose: clickable HTML demonstrators the client reacts to, before anything is
built.
Done when: never. One file per demonstrator prototype brief.

Every file here is a scoping prototype under guardrail 9. It is disposable, it
is not product code, and it is never promoted into a code space.

One brief, one self-contained file. No fragments, no shared assets, no build
step, no dependencies. Client data stays local (guardrail 5).

A file here is reached from its brief in `project/artifacts/`, which is reached
from the delivery that needed it. The chain is the trace. Nothing here links
back up.

`/fde:prototype` writes these. Its reference walkthrough of the worked
example lives with that skill, in the `fde` plugin.
