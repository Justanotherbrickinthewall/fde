# Assumptions

Purpose: things treated as true without a source good enough to cite.
Done when: never. An assumption that affects scope or architecture is
validated before the thing it supports is built.

Aggregated, not authored: an assumption is tagged `(assumption)` at the
point of use in the wiki and collected here.

```bash
grep -rn "(assumption)" wiki/
```

| ID | Assumption | Where used | What breaks if wrong | Validation | Who can perform it | Status |
|---|---|---|---|---|---|---|
| | | | | | | |

Statuses: unvalidated, validated, invalidated, no longer relevant. A row
with no named validation is a hope, not an assumption. Low-impact
assumptions do not need validating; recording them is enough.
