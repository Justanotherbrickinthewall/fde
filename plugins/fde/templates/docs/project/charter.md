# Charter

Purpose: what we are doing for this client, and how we will know it worked.
Done when: every required row holds an agreed answer, not our guess.

Write this first, before it can be filled in. The empty rows are the
discovery agenda. `/fde:fdc-session` fills them as material arrives.

Every claim in this file carries a tier. `artefact` means the client wrote
it down. `stated` means a named person said it. `ours` means we inferred
it. An `ours` row on anything that matters needs a client question beside
it in [`open-questions.md`](open-questions.md).
